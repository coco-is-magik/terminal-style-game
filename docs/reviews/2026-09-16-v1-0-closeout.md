## Exit-gate reconciliation

1. **Baseline and final evidence:** strict builds, the complete functional aggregate,
   UI standards, SMC modes, sanitizers, standards-core, smoke, benchmarks, stability,
   required Linux profiles, and scoped native Windows evidence are recorded in the
   V1-0 plan and its linked records.
2. **Required platforms:** Ubuntu GCC and Fedora GCC profiles pass. Native Windows 10
   x64 UCRT64 passes strict application compilation and all 64 registered test runners.
   Ubuntu Clang remains an informational strict diagnostic profile with exactly four
   pinned-SMC final-newline findings deferred to V1-20.
3. **Native Linux display/input:** `make display-acceptance-linux` passed on the native
   X11 host on 2026-09-16. X11/OpenGL presented and resized the application, accepted
   keyboard and synthetic-host XTest pointer motion/down/up, completed an application
   state transition, and exited after 12.042 seconds and 1,459 frames. The captured
   image was a 1366x768 PNG. XTest is synthetic host input, not physical-device proof.
4. **Performance and stability:** the optimized surface and optical paths pass their
   unchanged 6 ms budgets. Complete `benchmark-headless` and `stability-headless` pass;
   deterministic checksums and zero optical render-loop allocations are retained.
5. **Mirror classification:** a distinct complete-path planar projection defect was
   reproduced, corrected, manually confirmed, and locked by analytic final-frame and
   wall/floor/ceiling continuation regressions. One bounce, cache bounds, frontier
   semantics, darkness fallback, and allocation behavior remain unchanged.
6. **Byte inventory:** no runtime-authored asset contains a non-ASCII byte.
   `assets/README.md` is documentation and is classified separately. No legacy byte was
   assigned host-code-page meaning.
7. **Residual work:** the exact four-file pinned-SMC newline/source-pin correction is
   explicitly deferred to V1-20. Cppcheck 2.18.2 subsequently became available; four
   serializer pointer-array findings were hardened, the tool's analysis-scope information
   was narrowly classified, and real `make standards` plus complete `make -j2 check`
   passed. See `reviews/2026-09-16-cppcheck-gate-recovery.md`.
