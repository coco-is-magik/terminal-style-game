## Architecture review

### Ownership

`SceneDocument` is the sole authoritative owner of authored scene data (map
cells, spawn, ambient, lights, decals, stable IDs, path, dirty state, provenance,
repair state). The derived `WorldState` runtime view is disposable and rebuilt
transactionally; it is never a second editable source of truth. This satisfies
roadmap principle 2.

### Dependency direction

The intended direction (formats → domain documents → runtime adapters →
renderer/collision/lighting; editor UI → domain commands) is respected.
`scene_format`, `scene_diagnostic`, `scene_document`, and the derived runtime
adapter sit on the correct side of the boundary. No domain logic leaked into
`app.c` or the renderer.

### Migration and compatibility

Legacy digit-grid import is non-destructive (source bytes unchanged), captures
defaults once, retains optional provenance, and routes Save to Save As. Native
`.tscene` v1 is versioned and discriminated by parsed `scene_type`/`scene_version`,
not by extension alone. Missing decal references commit in visible repair mode
with preserved authored references and Save blocking.

### Failure atomicity

Native load, import, and runtime rebuild are transactional: a rejected candidate
cannot alter the live document, history, selection, path, dirty state, or derived
runtime view. Durable Save uses a same-directory temporary file with
flush/sync/close/rename/directory-sync; pre-rename failures preserve destination,
path identity, and dirty state; rename failure retains the completed temporary
file; directory-sync failure is a committed Save with a durability warning.

### Duplicate state

The duplicate mutable map/runtime state was retired in Increment 9. The legacy
direct-open document model is gone; the legacy-current chooser and F5 reload route
through the import/native boundaries. The remaining deprecated symbols are
unreachable-by-invariant and guarded.

## Manual acceptance (video-gated, pending)

The following interactive checks must be run in a video/SDL environment and
recorded before R2 is fully closed:

```sh
make clean && make
./build/ascii-fps
```

1. **New:** `Ctrl+N` creates a dirty unsaved 10 by 6 bordered scene.
2. **Open native:** open a `.tscene`; verify lights/decals/ambient/spawn render.
3. **Import legacy:** import a `.txt`; verify source bytes unchanged, document
   dirty/unsaved, Save routes to Save As.
4. **Save / Save As:** `Ctrl+S` and `Ctrl+Shift+S`; verify `assets/scenes/<name>.tscene`.
5. **Reload:** `F5` on a native scene preserves lights/decals/ambient; dirty
   reload prompts.
6. **Dirty close / exit:** Save/Discard/Cancel; failed save does not discard.
7. **Repair mode:** open a scene with a missing decal reference; verify visible
   fallback, Save blocked, explicit replacement unblocks.
